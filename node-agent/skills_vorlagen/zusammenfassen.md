---
name: zusammenfassen
description: Einen langen Text so zusammenfassen, dass ich in einer Minute weiß, was drinsteht.
---

Ich gebe dir einen Text. Fass ihn so zusammen:

Erste Zeile: worum es geht, in einem Satz. Dann höchstens fünf Zeilen mit einem Gedankenstrich, je eine Aussage, die wirklich im Text steht, die wichtigste zuerst. Zahlen, Namen und Daten übernimmst du genau. Zum Schluss ein Satz: was ich tun sollte oder entscheiden muss, wenn der Text das verlangt, sonst nichts.

Erfinde nichts dazu und lass nichts weg, was Geld, Fristen oder Pflichten betrifft. Wenn der Text unklar ist, sag, an welcher Stelle.
