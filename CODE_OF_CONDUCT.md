# Code of conduct

KIplatz has one set of rules for every place where people meet: the forum, the workshop, the program and this repository. They are called the **house rules** (German: Platzordnung) and they are short: stay friendly, welcome newcomers, stay on topic, stay honest, keep other people's data private, and don't use KIplatz to harm anyone.

The full text, in English: [kiplatz.com/house-rules](https://kiplatz.com/house-rules/). Auf Deutsch: [kiplatz.at/hausordnung](https://kiplatz.at/hausordnung/).

If someone breaks the rules here, write to support@kiplatz.at. We answer within 48 hours.
